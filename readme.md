# Deepak Babu Portfolio

A responsive static portfolio for Java development, backend projects, software testing and QA automation.

## Files

- `index.html` - portfolio content and page structure
- `css/style.css` - responsive visual design
- `js/script.js` - mobile navigation, project filters, clickable project details, email copy and reveal animation

## Run locally

Open `index.html` directly in a browser.

Optional local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
